## 第九轮（0927）：菱形/五角星偏很多 —— 比例插补换向竞态 bug

- 现象：比例速度软件插补（mode 3）画圆形/正方形基本正常，画菱形和五角星偏差很大。
- 根因分析（形状特征完全吻合）：
  - 圆形 72 段小角度过渡，每个半圈才换一次轴方向；菱形**每个顶点恰好一根轴反向**、五角星大多数顶点换向 → 换向形状最容易踩竞态。
  - **bug ①（主因）**：轴减速到 0 的瞬间 `dmc_check_done` 已报"停止"，但控制器内部 CHECK_DOWN 还没完成，紧接着的 `dmc_pmove_unit` 报 **1002（轴 CHECK_DOWN 未完成）**，指令被拒绝——原代码**不检查 pmove 返回值**，一根轴没动另一根照走 → 该段轨迹直接歪掉。
  - **bug ②**：起始/停止速度设 0（默认 txtMinV=0）在总线轴上 profile 设置可能被拒绝（返回值也没检查）→ 两轴速度比失效，长对角线段弯曲。
- 修复（Form2.RunProportional 重写）：
  1. `PmoveWithRetry`：pmove 返回 1002/4/1001 时 sleep(10ms) 重发，最多 30 次；
  2. `FloorSpeed`：min/stop 速度 ≤0 时取该轴最大速度的 5%（两轴同比例，保持直线）；
  3. `dmc_set_profile_unit` 返回值全部检查，失败即报错终止；
  4. 每段 `WaitBothDone` 后加 15ms 稳定延时再发下一段。
- 如果修复后预览（指令位置）正确但机器实物仍偏 → 机械反向间隙（backlash）：菱形/五角星每个角双轴同时换向，间隙全部体现；圆/方形每半圈才换一次向。可在驱动器侧查反向间隙补偿。
